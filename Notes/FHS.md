The Filesystem Hierarchy Standard defines what each top-level directory holds.

| dir | content |
|---|---|
| etc | configuration of the system and the services |
| var | variable files: logs, databases, spools |
| bin, sbin | essential binaries |
| boot | boot loader files |
| dev | device files |
| lib | essential shared libraries |
| media, mnt | mount points, removable and temporary |
| opt | add-on software packages |
| proc, sys | kernel, process and device interfaces |
| run | data for running processes |
| srv | data served by this system |
| tmp | temporary files |
| usr | secondary hierarchy |
| home, root | home directories |

See [[Pseudo filesystems]], [[The usr merge]]
